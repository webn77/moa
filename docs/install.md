# 모아를 우리 팀 Slack 에 설치하기 (#50)

**걸리는 시간 10분.** 사람이 하는 일은 **클릭 두 번 · 붙여넣기 두 번**이고, 나머지는 스크립트가 한다.

코드는 하나, 팀마다 **데이터 폴더** 하나다. 데이터 폴더에 `config.json`(채널·캔버스 ID) · `project.md` ·
`team.md` · `roadmap.md` · `cards.json` · `issues/` 가 들어간다. **토큰은 데이터 폴더에도 레포에도 두지 않는다.**

## 왜 「Slack 에 추가」 버튼 한 번이 아닌가

Socket Mode(서버 없이 도는 방식)는 **앱 레벨 토큰**을 쓰는데, 이 토큰은 **사람이 브라우저에서 만들어야 한다 — API 가 없다.**
버튼 하나로 끝내려면 우리가 서버를 띄워 토큰을 대신 들고 있어야 하고, 그러면 팀의 대화가 우리 서버를 지나간다.

**지금은 각 팀이 자기 앱·자기 토큰·자기 컴퓨터로 돌린다.** 남의 서버를 거치지 않는 대신 붙여넣기를 두 번 한다.
설치가 끝나면 그 뒤로는 손댈 일이 없다.

| | 누가 |
| --- | --- |
| 앱 이름 · 소개 · 명령 · 권한 · 이벤트 설정 | **자동** (링크에 매니페스트가 실려 있다) |
| 채널 2개 · 캔버스 · 팀 문서 기본 틀 · 설정 파일 | **자동** |
| 앱 만들기 Create · Install | 사람 (클릭 2번) |
| 토큰 2개 복사 | 사람 (붙여넣기 2번) |
| 앱 아이콘 | 선택 — 안 해도 된다 |

## 0. 먼저 점검 — 막힐 것을 미리 잡는다

```bash
python3 setup.py --check
```

Slack 에는 아무것도 만들지 않고 **파이썬 · `claude` · 토큰 · 매니페스트**를 잰다.
막히는 곳마다 **칠 명령을 그대로 찍어 준다.** `claude` 는 있는지만 보지 않고 **실제로 한 번 불러 본다** —
로그인은 됐는데 모델 이름이나 옵션에서 터지는 경우가 있다 (그러면 봇은 Slack 에 붙는데 **생각만 안 한다**).

## 1. 앱 만들기 — 클릭 두 번

```bash
python3 setup.py --app-link
```

나오는 링크를 열면 앱 만들기 화면이 **미리 채워진 채로** 뜬다. 이름(프로덕트 에이전트) · 표시 이름(PA) ·
소개 · 명령 · 권한이 전부 들어 있어서 손으로 채울 것이 없다.

1. **Create** 누르기
2. 왼쪽 **Install App** → **Install to Workspace** → 권한 허용

## 2. 토큰 두 개 — 붙여넣기 두 번

**① 봇 토큰** 왼쪽 **OAuth & Permissions** → 맨 위 `Bot User OAuth Token` (`xoxb-` 로 시작) 복사

**② 앱 토큰** 왼쪽 **Basic Information** → 아래로 내려 **App-Level Tokens** → **Generate Token and Scopes**
→ 이름 아무거나 → **Add Scope** 에서 `connections:write` → **Generate** → (`xapp-` 로 시작) 복사

```bash
python3 setup.py --data ~/teams/우리팀 --project "우리 팀 프로젝트" --pm U0123ABC \
                 --env-file ~/.config/우리팀.env --ask-tokens
```

- 토큰 두 개를 차례로 물어본다. **붙여 넣어도 화면에 보이지 않고**, 파일 권한 600 으로 저장한다
- 이어서 채널 두 개(`#팀-대화` · `#프로젝트-<이름>`)와 캔버스를 만들고 팀 문서 기본 틀을 채운다
- **PM 멤버 ID**: Slack 프로필 → ⋯ → **멤버 ID 복사** (`U` 로 시작)
- **먼저 보고 싶으면** `--dry-run` — Slack 에 아무것도 만들지 않고 무엇을 할지만 보여 준다
- **GitHub 도 쓰려면** `--github owner/repo` (없으면 기록 파일만 쓴다). 나중에 Slack 에서 「깃허브 등록」 으로도 붙일 수 있다

## 3. 실행

```bash
MOA_DATA=~/teams/우리팀 python3 bot.py
```

팀 대화방에서 **`@PA`** 라고만 쳐 보면 뭘 할 수 있는지 안내가 뜬다. `🎫 첫 요청` 을 쓰고
프로젝트 방에 카드가 생기면 성공이다.

**재부팅 뒤에도 돌게** — `setup.py … --launchagent` 가 데이터 폴더에 plist 를 써 준다.
설치 명령은 스크립트가 알려 준다 (회사 맥은 IT 정책을 먼저 확인).

## 4. (선택) 앱 아이콘

**Basic Information → Display Information → App icon** 에 `assets/pa-icon-white-1024.png` 를 올린다.
Slack 매니페스트에 아이콘 항목이 없어서 이것만 손으로 올린다.
안내문에는 512~2000px 이라고 나오지만 **딱 512 는 거절당한다** — 1024 를 쓴다 (2026-09-20 실측).

**안 올려도 된다.** 대화에 보이는 이름과 얼굴은 봇이 **메시지마다 실어 보내므로** 이미 PA 로 보인다.
앱 아이콘은 앱 목록과 앱 홈 머리에만 쓰인다.

## 5. (선택) 구글 캘린더 연결

회의를 만들면 구글 캘린더에도 올라가고 알림·참석 응답은 이미 깔린 **Google Calendar for Slack** 앱이
한다 (PA #45). 봇은 **연결한 계정 안에 「모아」 라는 보조 캘린더를 스스로 만들고 그것만** 다룬다 —
다른 일정에는 손대지 않는다.

1. [Google Cloud Console](https://console.cloud.google.com/) → **새 프로젝트** (다른 용도 프로젝트에 섞지 않는다 —
   동의 화면·게시 상태를 같이 쓰게 된다). 결제 계정 칸이 필수로 뜨면 골라도 된다 — Calendar API 는 무료다
2. **Calendar API** 를 사용 설정 (API 및 서비스 → 라이브러리)
3. **OAuth 동의 화면**(Google 인증 플랫폼): 앱 이름 · 지원 이메일 · 대상 **외부** · 연락처 → 만들기 →
   「대상」 에서 연결할 계정을 테스트 사용자로 추가
4. **클라이언트** → 만들기 → 유형 **데스크톱 앱** → JSON 다운로드 → 데이터 폴더에 `gcal_client.json` 이름으로 둔다
   (Claude 앱 안 브라우저는 내려받기가 안 된다 — 맥의 브라우저로 받는다)
5. `MOA_DATA=~/teams/우리팀 python3 gcal.py connect` — **`MOA_DATA` 를 꼭 같이 줘야 한다**
   (안 주면 코드 폴더를 데이터 폴더로 보고 `config.json` 이 없다며 멈춘다). 브라우저 주소가
   뜨면 열어서 로그인·동의하고, 「모아」 캘린더를 만든다

6. **7일마다 끊기지 않게 — 프로덕션으로 게시.** 「테스트 중」 이면 토큰이 7일 뒤 만료된다. 브랜딩에
   홈페이지 · 개인정보처리방침 링크 · 승인된 도메인을 채우면 「대상 → 앱 게시」 가 켜진다
   (모아는 `https://github.com/webn77/moa` · `…/blob/main/PRIVACY.md` · `github.com` 을 쓴다).
   게시한 뒤 **5번을 한 번 더** 돌려 새 토큰을 받는다 — 테스트 중에 받은 토큰은 만료가 남는다.
   심사는 안 받으므로 연결할 때 「확인되지 않은 앱」 이 뜬다 → 고급 → 이동. 누적 100명까지

회의 ⑤ 에서 고른 사람(@사람 · 모두 · 나만)을 초대한다. 초대 주소는 **Slack 가입 이메일**이다.

연결 안 해도 봇은 그대로 돈다 — 회의 카드만 생기고 캘린더에는 조용히 안 올라간다(`bot.log` 에 한 줄).
초대 대상·회의 길이는 데이터 폴더 `config.json` 의 `gcal`(`invite`: `"owner"`|`"room"`, `minutes`)로 바꾼다.
`invite: "room"` 을 쓰려면 `users:read.email` 권한이 있어야 하고, 그러려면 **앱을 재설치**해야 한다(위 참고).

## 채널 두 개의 역할

| 채널 | 무엇을 하나 |
| --- | --- |
| **#팀-대화** (하나) | **일하는 곳.** 사람과 AI 가 같이 본다 — 요청 · 확인 부탁 · 시작·완료 알림 |
| **#프로젝트-<이름>** (프로젝트마다) | **기록 보관소.** 이슈 카드 · **회의 카드** · ⚙️ 설정 · 날짜별 기록 · 작업판(캔버스) · GitHub 동기화 |

## 팀에 맞게 고치기

데이터 폴더의 `project.md`(문제 · 목표 · 할 일 · 기능) · `team.md`(사람 · 역할 · 최대 동시 · 주당 시간) ·
`roadmap.md`(단계 · 날짜)를 채운다. 틀과 채우는 법은 `templates/project-goal.md`.
봇 말투를 바꾸려면 데이터 폴더에 `messages.json` (`{"키": "문구"}`) — 키 목록은 `messages.py`.

## 봇은 **이 맥에서** 돈다 — 끄면 멈춘다

모아는 서버가 아니라 **설치한 맥에서 도는 프로그램**이다. 개인 맥북에 둬도 된다 —
다만 **그 맥이 꺼지거나 잠들면 봇도 멈춘다.** Slack 에 글을 남겨도 아무 일도 일어나지 않고,
다시 켜면 그때부터 다시 받는다 (그 사이에 온 말은 놓친다).

팀이 쓰려면 셋 중 하나다.

| | 어떤 경우 | 해 둘 것 |
| --- | --- | --- |
| 개인 맥북 | 혼자·소수로 시험할 때 | **잠들지 않게** — 시스템 설정 → 잠금 화면 → 디스플레이 끈 뒤 잠자기: 안 함 |
| 늘 켜 두는 맥 | 팀이 쓸 때 (맥 미니 등) | 자동 로그인 + 잠자기 끄기. LaunchAgent 가 알아서 다시 띄운다 |
| 서버 | 팀이 오래 쓸 때 | 리눅스에서도 돈다 (파이썬 3.11+ · `claude` 명령). 문서는 아직 없다 |

**기록을 레포에 붙여 두면** (프로젝트 만들 때 ④번째 칸) 맥이 꺼져도 그때까지의 할 일·회의록은
레포에 남는다. 안 붙이면 그 맥에만 있다.

## 필요한 것

- 맥 (또는 항상 켜 둔 컴퓨터) · Python 3.11+ · `pip install aiohttp pyyaml`
- Claude Code 로그인 (`claude auth status`) — 봇의 AI 는 이 구독으로 돈다. 팀 상시 운용 전 약관 확인 (#16)
- GitHub 연동 시 `gh auth login` (Projects 보드는 `gh auth refresh -s project`)

## 막혔을 때

| 증상 | 이유와 조치 |
| --- | --- |
| `봇 토큰이 맞지 않아요` | `xoxb-` 로 시작하는지 · Install to Workspace 를 눌렀는지 |
| 봇이 아무 반응이 없다 | 앱 토큰(`xapp-`)에 `connections:write` 가 붙었는지 · `bot.log` 에 「연결됨」 이 있는지 |
| 캔버스가 `restricted_action` | 봇이 그 채널에 없다 — `/invite @PA` |
| `#40` 을 써도 안 펼쳐진다 | 봇이 그 채널에 초대돼 있어야 한다 |
| 봇이 두 개 떠 있다 | `pgrep -fl bot.py` 로 확인하고 옛것을 `kill`. 두 개면 옛 코드가 이벤트를 먼저 먹는다 |
| 권한·이벤트를 바꿨다 | 앱을 **재설치**해야 반영된다 (Install App → Reinstall) |
| DM 탭은 생겼는데 글이 안 써진다 | `messages_tab_read_only_enabled: false` 를 적지 않으면 Slack 이 **읽기 전용**으로 켠다 (2026-09-20 실측) |
| 매니페스트 저장이 `shortcuts` 줄에서 막힌다 | 메시지 단축키에 `commands` 권한이 필요하다 — 슬래시를 빼도 이건 남긴다 |
| 앱 만들기에서 `We can't translate a manifest with errors` | 앱 이름이 **3글자 미만**이거나 부르는 이름에 **한글**이 있다. `--check` 가 미리 잡아 준다 (2026-09-22 실측) |
| `@모아` 로 안 불린다 | 부르는 이름은 **영문만** 된다 — Slack 이 거기서 아이디를 만드는데 한글은 못 바꾼다. 메시지에 보이는 이름은 `--bot-name 모아` 로 한글로 둘 수 있다 |
| 작업판 탭이 「제목 없음」 | **API 로 못 정한다** — 채널 캔버스의 제목 칸은 `canvases.edit` 가 안 받는다 (2026-09-22 실측). 탭을 열고 맨 위 「내 캔버스 제목」 자리에 한 줄 치면 된다 |
| 앱 아이콘이 안 바뀐다 | **API 로는 못 올린다** — 매니페스트에 아이콘 항목이 없다. Basic Information → Display Information 에서 사람이 한 번 (`assets/moa-icon-1024.png`, 512 는 거절당한다) |
| 브라우저에서 매니페스트 붙여넣기가 안 된다 | 붙여넣기가 막힌 브라우저가 있다 — `--app-link` 가 주는 링크를 쓰면 붙여넣을 일이 없다 |

## 한 맥에서 여러 팀

팀마다 데이터 폴더 · 토큰 파일 · Slack 앱이 따로다. `MOA_DATA` 만 바꿔 봇을 팀 수만큼 띄운다.

## 이미 만들어 둔 앱의 이름을 바꾸려면

매니페스트 없이 먼저 만든 앱(이 저장소의 옛 `sandbox-bot` 같은)은 한 번 따라잡아 줘야 한다 —
`manifest.yaml` 맨 위 주석의 순서를 따른다. **새로 설치하는 팀은 그럴 일이 없다.**
