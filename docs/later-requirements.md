# 나중 요건

지금 단계(개발·도그푸딩 → PoC)에서는 만들지 않지만 잊으면 안 되는 요건. 각 요건은 팀 이슈로도 등록한다.

## 1. 개인 요청 입구 — 메일·Slack DM 으로 온 요청을 팀 이슈로
- **왜**: 요청은 #팀-대화 로만 오지 않는다. 개인 메일·DM 으로 온 요청이 팀에 안 들어가면 흘러간다
- **원칙**: 개인 채널은 사람이 고른 것만 팀으로 넘긴다. 봇이 개인 메일·DM 을 전부 읽지 않는다
- **안**
  - A (먼저): 메일은 Gmail → Slack 보내기, DM 은 메시지 단축키 「이슈로 만들기」 → 봇이 할 일을 뽑아 「이슈로 만들까요? [만들기] [무시]」
  - B (나중): Gmail 「프로젝트」 라벨이 붙은 메일만 봇이 읽고 같은 방식으로 제안 — Gmail 읽기 권한 · 메일 규칙(계속 남는 설정) 승인 필요
- **확인할 것**: Gmail 용 Slack 부가기능이 무료 Slack 에서 되는지 · 기존 `mail-agent` 앱과 겹치는지

## 2. 팀 일정 — Google Calendar 연결
- **왜**: Slack 에는 일정 관리가 없다. 회의·마감이 캘린더에 없으면 사람마다 따로 챙겨야 한다
- **안**
  - 1단계: 공식 「Google Calendar for Slack」 앱 — 사람마다 일정 알림 · 회의 중 상태 자동 표시 (사람마다 설치)
  - 2단계: 봇이 팀 캘린더에 쓴다 — `/meeting` 이 캘린더 일정(+ Meet 링크)을 만들고, 이슈 마감(#34)을 팀 캘린더에 올리고, 캔버스에 「이번 주 일정」 을 보여 준다
- **확인할 것**: 무료 Slack 앱 10개 한도 안에 들어가는지 · 봇이 캘린더에 쓰는 인증 방식 (서비스 계정 / 사용자 OAuth — 인증 정보는 사람이 넣는다)

## 3. 아이디어·백로그 보관함 — 번호는 실제 작업이 될 때만 (2026-09-20 사용자 의견)
- **왜**: 아이디어·백로그도 어딘가 저장돼야 잊히지 않는다. 하지만 전부 번호 붙은 이슈가 되면 관리 채널이 어지럽고, 사람이 할 일과 그냥 적어 둔 것이 섞인다
- **원칙**: 실제 작업으로 등록된 것만 사람이 진행한다. 아이디어·백로그는 보관만 하고 번호를 붙이지 않는다
- **안 (정리만, 아직 만들지 않음)**
  - 🎫 한 줄 → 번호 없는 보관함(백로그 목록)에 들어가고 AI가 우선순위만 매긴다. 앱 홈 · `/백로그` · 캔버스 「다음 후보 Top 5」 로 본다
  - 가져올 때(✋ · PM 이 P1 지정 · 「자리가 났어요, 가져가실래요?」) 번호가 붙고 카드가 생긴다
  - 채널 역할: #팀-대화 = 일하는 곳(사람은 여기서만 대화) · #프로젝트-○○ = Jira·Linear 같은 관리 도구(상태 · 기록 · 날짜별 진행을 볼 때만)
- **정할 것**: 구체화 대화를 요청 스레드로 옮길지 · 자리가 나면 자동 배정 대신 추천만 할지 · 이미 번호 붙은 담당 없는 26건 처리
