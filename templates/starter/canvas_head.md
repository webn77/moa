## 🧭 여기서 일하는 법

| 하고 싶은 것 | 이렇게 하세요 |
| --- | --- |
| 할 일을 올리고 싶다 | **#{request}** 에 🎫 로 시작하는 **한 줄** (또는 `@{bot} 할 일로 만들어줘`) → 카드가 생기고 봇이 스레드에서 몇 가지 물어봐요 |
| 할 일을 구체화하고 싶다 | 카드 스레드에서 봇 질문에 **그냥 답하면** 돼요 → 정리안이 오면 **👍 이대로** |
| 내가 맡겠다 | 카드의 **✋ 내가 할게요** |
| 담당 · 우선순위 · 목표일을 바꾸고 싶다 | 카드 스레드 맨 위 **⚙️ 이 할 일 설정** 에서 골라요 |
| 진행 중 · 보류 · 완료 | 카드에 👀 · ⛔ · ✅ 반응, 또는 ⚙️ 설정의 상태. 담당자가 ✅ 하면 🔍 확인 대기 → 요청하신 분이 팀 대화방에서 **확인했어요** 를 누르면 완료 |
| 내용을 고치고 싶다 | 카드의 **📄 상세** → **✏️ 내용 수정** |
| 얼마나 했는지 알리고 싶다 | 카드 스레드 맨 위 **⚙️ 설정** 의 체크리스트를 체크 → 카드에 `2/4` 처럼 보여요. 다 체크하면 확인 대기로 |
| 무엇이 언제 바뀌었나 보고 싶다 | 카드 스레드의 🔄·📝 한 줄, 또는 **{bot} 홈 → 📆 날짜별 진행** |
| 회의를 잡고 싶다 | {bot} DM 에 **「회의 만들자」** → 무슨 회의 · 프로젝트 · 한 번/정기 · 언제 · 누구를 여쭤요 → 프로젝트 방에 회의 카드 · 구글 캘린더 초대(연결한 팀) · 10분 전 알림. 카드의 **✍️ 논의 적기** → **📝 회의록 확정** |
| 궁금한 걸 묻고 싶다 | 카드 스레드에 **물음표로 끝나는 질문**, 또는 `@{bot}` |
| 프로젝트 현황이 궁금하다 | `@{bot} 현황` (평일 아침 9시에는 자동으로 올라와요) |
| 작업판이 겹쳐 보이거나 옛 내용이 보인다 | 탭을 닫았다가 다시 열어 주세요. 작업판은 10분마다 모아서 고쳐요 — 바로 보려면 **{bot} 홈 → 🔄 작업판 새로고침** |
| 그냥 이야기하고 싶다 | **#{request}** 에서 편하게. 🎫 가 없으면 할 일이 되지 않아요 |

> 💡 우선순위 · 담당 · 목표일은 AI가 먼저 채워 둬요. 다르면 사람이 고치고, 사람이 고친 값은 AI가 덮어쓰지 않아요.
