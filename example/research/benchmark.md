# 🔍 벤치마킹 — Slack 안의 AI 프로젝트 비서

조사일 2026-09-19. 비교 기준은 우리가 만든 기능. 확신도는 높음 · 중간 · 낮음으로 표시한다.

## 한 줄 결론
**「Slack 쓰는 팀을 위한 AI 프로젝트 비서」 자리는 비어 있다 — 확신도 중간.** 국내 최근접은 플로우 「리패턴」(자기 협업툴 안에서만 동작).

## 왜 Jira·Linear가 아닌가

| | Jira · Linear | 우리 |
| --- | --- | --- |
| 일하는 곳 | 별도 프로그램 (Slack 연동은 알림·입구 정도) | Slack이 메인 화면, GitHub는 밑단 저장소 |
| 입력 | 사람이 옮겨 적는다 | 대화가 곧 입력, 봇이 모아서 정리 |
| AI | 검색 · 요약 · 분류 (사람이 불러야 움직임) | 비서가 먼저 움직인다 — 나누고 · 알리고 · 기록 |
| 쓰는 사람 | 익숙해야 쓴다 | Slack만 쓸 줄 알면 된다 |
| 비용 | 사람당 월 과금 | 무료 Slack + GitHub |

Linear Asks(Slack 메시지 → 이슈)·Jira Rovo(AI)도 있다. 차이는 「AI가 있냐」가 아니라 「Slack이 본거지이고 AI가 비서로 먼저 움직이냐」.

## 해외

| 기능 | 우리 | Tickr | Chaser |
| --- | --- | --- | --- |
| 메시지 → 이슈 | 🎫 · 단축키 · /issue | 부분 (자연어 명령) | 있음 (단축키·슬래시) |
| 역할표 기반 자동 배정 | 있음 | 없음 (수동) | 부분 (역할 무관 순번) |
| 공개 계산식 우선순위 | 있음 | 부분 (비공개 규칙) | 없음 (수동 태그) |
| 사람별 최대 동시 수 + 자동 당김 | 있음 | 없음 | 없음 |
| 예상 시간 · 일정 점검 | 있음 | 부분 (시간 추적·지연 예측) | 부분 (시간 추적) |
| 스레드 → 이슈 정의 | 5칸 | 부분 (액션 아이템) | 부분 (회의 메모 → 액션) |
| 회의 → 변경 제안 → 승인 → 반영 | 있음 | 없음 (스탠드업만) | 부분 |
| 정본 | GitHub md | 미확인 | 자체 DB (미국 Azure) |
| 가격 | 무료 Slack + 구독 | $12~18/인·월 | $7~16/인·월 |

## 국내

| 구분 | 누가 | 관계 |
| --- | --- | --- |
| 협업툴 AI | **플로우 「리패턴」** — 대화·엑셀·템플릿 → 업무 생성 + 담당 + 우선순위 + 일정 (유료 상위 요금제) | 최근접. 자기 협업툴 안에서만 |
| 협업툴 AI | 두레이 AI 에이전트 (2026-04) | 자기 협업툴 안에서만 |

| 외산 한국 출시 | 세일즈포스 Slackbot (2026-04) | 범용 비서 — 배정·우선순위 아님 |
| Slack 구축 대행 | 허밍버즈 (세일즈포스 파트너) | 제품 아님 — 잠재 파트너 |

## 우리만 있는 것과, 남들에게 없는 이유

| 기능 | 없는 이유 | 불편해서? | 우리 대응 |
| --- | --- | --- | --- |
| AI 담당 배정 | 자율성 상실이 AI 거부감의 핵심 (HBR 2026-09) | 그렇다 | 추천까지만, 확정은 본인 👍 |
| 공개 계산식 우선순위 | 점수 입력이 귀찮아서 가벼운 도구엔 없음 | 무거워서 | AI가 점수를 채운다. 사람이 고치면 고정 |
| 동시 작업 제한 + 자동 당김 | 칸반 기본이지만 Slack 봇엔 없음 | 반반 — 통제로 느낄 수 있음 | 「뒤로 보냈어요」 알림 + 되돌리기 (#33) |
| 회의 → 제안 → 승인 | 추출에서 끝나는 도구가 대부분 | 반반 — 단계가 늘어남 | 1클릭 승인 |
| GitHub md 정본 | 개발자 중심 | 비개발자에게 그렇다 | 정본은 유지, 화면에서는 숨김 |
